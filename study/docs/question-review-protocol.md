# Revisão de questões

A planilha existente continua canônica. O auditor lê um snapshot privado; não altera itens, chaves, status ou histórico. Execute `node study/scripts/audit-bank.mjs /caminho/privado/snapshot.json` e redirecione o resultado para armazenamento privado.

A conferência automática verifica estrutura, tópico, alternativas e evidências. Os estados legados “Revisada automaticamente”, “Validada na fonte” e “Elegível” não são aprovação editorial humana.

O revisor humano deve conferir enunciado e fonte, justificar a correta e cada distrator, registrar eventual ambiguidade, data e identificador editorial, e aprovar o hash exato. Use o modelo JSON. Alterações de texto, chave, fonte ou alternativas exigem nova revisão. Uma aprovação é um registro de revisão efetivamente realizada, nunca uma propriedade a preencher para fazer o teste passar.

Questões autorais recebem esse rótulo mesmo quando o ID legado começa com FURB. Questões históricas exigem origem, gabarito oficial e condições de uso verificadas. Fonte do edital comprova o programa, não fundamenta sozinha a resposta de conteúdo. Não corrigir ambiguidades por inferência para alcançar uma meta numérica.
